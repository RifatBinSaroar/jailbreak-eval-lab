# Unmeasured templates only

Every record is marked `record_kind: template`, uses a `template-` ID and carries
a visible template note. These are illustrative shapes, not sourced literature,
implemented validators, approved designs, human annotations or experimental
outputs. No model or attack has been selected or executed.

The baseline `code_commit` is the actual scaffold commit
`9f673eadaa2b2364aa08f4cb4d2462e566ac7f80`, used only as a format example. The
experiment/run hashes are real hashes of these template definitions, not evidence
that an experiment ran. Replace source placeholders with retrieved sources.

All observation fields and metric values are null. Runs are planned, annotations
pending and results unmeasured. The generic benign-text taxonomy only illustrates
a domain/subdomain relationship. It makes no research-domain recommendation.

```bash
python -m jailbreak_eval.registry validate --directory examples/registries --allow-templates
```

The normal validator and website exporter reject these records. Create new
research IDs with reviewed metadata; do not relabel this set as research data.
