# Run bundles

No research experiment has been run by this implementation.

Future `python scripts/experiment.py record ...` commands create one immutable
`RUN-.../` directory here. Local run directories are ignored by Git by default.
Only deliberately reviewed, redistributable run artifacts should be committed.

See [the framework guide](../../docs/EXPERIMENT_FRAMEWORK.md) for file formats,
metric definitions, provenance, and the website rebuild command.
